OFFICIAL runs are executed end to end by the maintainer, three attempts per task, shown with ± spread. COMMUNITY results are submitted as raw model replies and re-graded against the private test suite, so scores cannot be faked. The site shows only the per-model average of all verified submissions — never individual results; token counts, cost, and time are averages of what submitters' clients reported. A community average wears ✓ once at least two independent submissions agree; ✗ means it still rests on a single submission. Scores are out of 100, weighted by task difficulty. The DL SCORE is the headline: every task carries a token budget — its deadline — and a solved task's points decay by budget÷tokens when the model blows past it. Correct but bloated loses to correct and lean. Runs without per-task token metering (subscriptions, agent mode) live on their own SUBSCRIPTION / AGENT board and carry a TIME-DL score instead — the same deadline idea with wall-clock budgets per task, from answer timestamps. The two boards are not directly comparable: API runs pay in tokens, agent runs pay in time. Costs use prices.json (USD per million tokens). SCOPE — Deadline measures exact Python 3, JavaScript (Node), and SQLite SQL with standard libraries only, across 27 machine-generated tasks — most reverse-engineered from the observed behavior of hidden systems — in one blind attempt against token deadlines. Two tasks are whole-project bug hunts across dozens of generated files.
