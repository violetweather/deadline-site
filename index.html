VERSIONS — Each result identifies its grading version. Deadline 3.4 keeps all public prompts and the submission format, but excludes 24_js_machine_traces from scoring because required state labels were not supplied. The 26 scored tasks total 1,205 points. Scores from different versions are not directly comparable. Correctness is the headline; token efficiency is separate. Version 3.4 balances semantic areas and applies continuous signed credit, including negative penalties. Unresolved blank replies remain incomplete. OFFICIAL identifies maintainer-run generations; existing entries have one attempt unless stated otherwise. A regrade reuses the same answer and does not add an independent sample. New certified runs require three attempts. Any displayed spread is repeat standard deviation, not a confidence interval. COMMUNITY answers are privately graded; model identity, effort settings and usage remain client reported. MEASUREMENTS — DL Score requires complete token measurements. Answer-file timestamps do not establish inference latency. TIME-DL uses archived answer intervals as a descriptive estimate; its timing coverage and assumptions are available in each expanded row. Agent rows rank by correctness. Local regrades awaiting isolation remain private. See methodology and limitations. SCOPE — Deadline measures exact Python 3, JavaScript (Node), and SQLite SQL with standard libraries only, across 27 machine-generated tasks — most reverse-engineered from the observed behavior of hidden systems — in one blind attempt against token deadlines. Two tasks are whole-project bug hunts across dozens of generated files.
