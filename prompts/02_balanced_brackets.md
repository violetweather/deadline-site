# balanced_brackets

Write a Python function:

    def balanced(s: str) -> bool

Return True if all brackets in s are balanced and correctly nested.
Bracket pairs are: (), [], {}. Ignore every other character.

Examples:
- balanced("([{}])") -> True
- balanced("(]") -> False
- balanced("a(b)c") -> True
- balanced("") -> True
