# rle_encode

Write a Python function:

    def rle(s: str) -> str

Run-length encode the string. For each run of equal characters, output the
character followed by the run length. Always include the count, even when it is 1.
Encoding is case-sensitive. Empty input returns an empty string.

Examples:
- rle("aaabb") -> "a3b2"
- rle("abc") -> "a1b1c1"
- rle("") -> ""
