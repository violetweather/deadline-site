# zapzip

Write a Python function:

    def zapzip(n: int) -> str

Rules:
- If n is a multiple of both 3 and 5, return "ZapZip".
- If n is a multiple of 3 only, return "Zap".
- If n is a multiple of 5 only, return "Zip".
- Otherwise return str(n).
- Treat 0 as a multiple of both (return "ZapZip").

Examples: zapzip(3) -> "Zap", zapzip(10) -> "Zip", zapzip(7) -> "7", zapzip(15) -> "ZapZip"
